# طَيْف — TAYF

مختبر ألوان ثنائي اللغة يعمل بالكامل داخل المتصفح.

## الميزات

- استخراج 6 ألوان من الصور محلياً عبر Canvas + k-means.
- توليد لوحات من لون أساسي بخمسة أنظمة تناغم.
- قفل الألوان وإعادة توليد الباقي.
- عرض HEX / RGB / HSL ونسخ اللون.
- فحص تباين حي ومعاينة واجهة واقعية.
- حفظ اللوحات في localStorage.
- تصدير CSS Variables وTailwind وJSON Design Tokens.
- واجهة عربية RTL وإنجليزية LTR من ملفات ترجمة منفصلة.
- تصميم متجاوب مع دعم prefers-reduced-motion.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الهيكلية

```text
src/
├── components/        # مكونات الواجهة والرسومات
├── i18n/
│   └── locales/       # ملفات العربية والإنجليزية
├── utils/             # اللون، الاستخراج، والتخزين
├── App.tsx            # تنسيق التطبيق وحالته
├── index.css          # نظام التصميم والحركات
├── main.tsx           # نقطة التشغيل
└── types.ts           # الأنواع المشتركة
```

لا توجد مدفوعات أو Backend في هذه النسخة؛ البنية جاهزة لإضافتهما لاحقاً.
